## Problèmes du jour du lancement : le rapport de crash sous Windows 11

Le signal post-lancement le plus concret est un crash au démarrage que rencontrent certains utilisateurs de Windows 11. Si vous êtes confronté au problème, suivez ces étapes dans l'ordre :

| Étape | Action |
| --- | --- |

Les retours de la communauté suggèrent que le problème n'est pas universel — de nombreux joueurs lancent le jeu sans difficulté. Mais c'est la plainte la plus fréquente dans les premiers fils de discussion, alors prévoyez quelques minutes de dépannage si vous êtes sous Windows 11.
