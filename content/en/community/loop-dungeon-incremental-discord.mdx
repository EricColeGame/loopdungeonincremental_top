## Community-Reported Fixes Worth Pinning

The most valuable thing the Loop Dungeon Incremental Discord and Steam hub produce is troubleshooting that actually works. Here are the ones that come up repeatedly.

### The Windows 11 "Failed to load il2cpp" crash

This is the big one. The developer's own investigation attributes it to Windows 11's Smart App Control, which flags the Unity IL2CPP library (`GameAssembly.dll`) as untrusted because the build isn't code-signed yet. A permanent fix — a code signing certificate plus updated Unity dependencies — is in progress. Until then:

| Symptom | Likely cause | Fix to try |
|---|---|---|
| "Fatal error: Failed to load il2cpp" at startup | Smart App Control blocking an unsigned DLL | Unblock all files in the install folder via right-click → Properties → Unblock |
| Crash persists after unblocking | Outdated local security definitions | Update Windows Security intelligence, then reboot |
| General launch crash | Renderer or driver conflict (player experience) | Add `-force-d3d11` as a Steam launch option |
| Still broken after all of the above | Unresolved signing issue | Report your Windows version and a screenshot to the developer |

The unblock step is the highest-yield fix: because the files arrived over the internet, Windows tags them with a "web mark," and clearing that mark resolves the block for most players.

### Other recurring reports

- **Locked skills after prestiging a demo save.** At least one player reported skills reverting to "get the full version" prompts after their first prestige in the full game. If you migrated a demo save, back it up before prestiging.
- **No ability autocast.** A common request — players describe manually firing abilities as "flask piano." Rebind keys or ask the community for a comfortable layout in the meantime.
- **Tooltip inaccuracies.** A tooltip info bug was fixed in a small patch, so make sure you're on the current build before reporting display errors.

Unblock the game's files first: right-click the game in your library, browse local files, select everything, open Properties, and check Unblock. Then update Windows Security intelligence and reboot. If it still fails, the developer is working on a code-signed build.
