## Loop Dungeon Incrementalのダンジョンループとは実際何なのか

ストアページは4語のモットーでまとめています。Build. Loot. Loop. Grow.（組み立て、戦利品、周回、成長）。これは構造を実に正確に言い表しています。パーティを編成し、パーティはダンジョンのフロアを自動で戦い抜き、戦利品とリソースを回収し、それらのリソースを永続的な強化に再投資してから、全員を再び地下へ送り出します。

重要なのは、ループは直線ではないという点です。それは螺旋です。あなたはコンテンツを繰り返しているのではなく、より高いパワーレベルで*プロセス*を繰り返しているのです。10回前の周回であなたのパーティを全滅させたフロアは、最終的に何も考えずに通過できる小さな段差になるはずです。

個々の要素がどう組み合わさるかは次のとおりです：

| ループの段階 | 何が起こるか | 何につながるか |
|---|---|---|
| パーティ編成 | ヒーローを募集し、役割のバランスを取り、編成を決める | 周回の安定性とクリア速度 |
| 降下 | ダンジョンフロアを自動戦闘で進む | 戦利品、通貨、リソース |
| 戦利品と投資 | 通貨を永続アップグレードに使う | 長期的なパワーカーブ |
| 壁 | 進行が鈍る、またはパーティが全滅する | リセットの合図 |
| プレステージ | 周回がリセットされ、永続ボーナスが適用される | 次回はより深いフロアへ |

この「壁」の段階は、プレイヤーが最もよく誤解する部分です。壁にぶつかることは失敗ではありません — 現在のループが払い出せるものはすべて払い出し終えたというゲームからの知らせであり、その進捗をプレステージの利益に変換する時だということです。

## 1回のループを構成する4つのフェーズ

Playsectはこのゲームを「毎回の周回があなたのパーティを強くする」と表現しており、その約束が成り立つのは、オートパイロットで同じボタンを連打するのではなく、ループの各フェーズをそれぞれ異なる扱い方をする場合だけです。

### Build：パーティを編成する

ヒーローにはそれぞれ異なる強みと役割があり、ゲームはキャラクター*と*アップグレードの間のシナジーを見つけることを明確に報酬として与えます。バランスの取れた編成は、4人のアタッカーだけの編成にほぼ毎回勝ります。なぜなら自動戦闘は脆さに厳しく、あなたは回避するためにそこにいるわけではないので、編成そのものが自力で生き残らなければならないからです。

### Loot：実際に何を拾ったのかを把握する

戦利品は単なる通貨ではありません。それは永続アップグレードの原材料であり、使う順序は総量よりも重要です。序盤では、広範な生存性アップグレードが狭い火力特化を上回る傾向があります。なぜなら、1フロア多く生き残ることは、敵を1体多く倒すよりも多くの戦利品を生み出すからです。

### Loop：自動化に任せる

戦闘は設計上自動です。このゲームはアクティブな最適化とパッシブな進行の両方をサポートするように作られており、つまりループはあなたが別のことをしていても回り続けます。トレードオフは、パッシブな進行が遅いことです — 周回の途中でパーティを調整しないため、ミスをリアルタイムで修正できないのです。

### Grow：周回を永続パワーに変換する

これが報酬のフェーズです。リソースはアップグレードになり、アップグレードは深さになり、深さはより良いリソースになります。そしてプレステージ層がそのすべてを倍増させます。

| フェーズ | あなたの役割 | よくある間違い |
|---|---|---|
| Build | 役割とシナジーのバランスを取る | 1種類のダメージに偏らせる |
| Loot | 計画を持って使う | 「後で使う」ために通貨を溜め込む |
| Loop | 戦闘を解決させ、結果を読む | 周回を早すぎるタイミングで中断する |
| Grow | リセット前に永続アップグレードを確保する | 何も投資せずにプレステージする |

## ループ内でのパーティの役割とシナジー

戦闘が自動化されているため、パーティ編成*こそが*あなたのゲームプレイです。ヒーローパーティ型インクリメンタルRPGの役割は概ねいくつかの枠に分類され、このゲームの構造は特化するよりもすべてをカバーすることを報酬として与えます。

| 役割 | ループ中の仕事 | なぜ重要か |
|---|---|---|
| 前線のタフガイ | ダメージを吸収し、戦線を維持する | 脆いヒーローを意味のある時間だけ生き延びさせる |
| 遠距離アタッカー | 敵の群れを素早く処理する | フロアごとのクリア速度を直接左右する |
| サポートまたはヒーラー | フロアをまたいでパーティを維持する | 1回の周回で到達できる深さを伸ばす |
| ユーティリティまたはコントロール | 味方を強化し、敵を弱体化する | パーティ内の他のすべての価値を倍増させる |

シナジーこそ、Loop Dungeon Incrementalのダンジョンループが面白くなるポイントです。遠距離アタッカーを強化するサポートヒーローは、2人目の遠距離アタッカーよりも価値があります。なぜならその倍率はアップグレードと競合するのではなく、積み重なるからです。新しいヒーローをアンロックしたとき、問うべきは「このヒーローはより強いか？」ではなく、「このヒーローは既存のヒーローをより良くするか？」です。

## プレステージ：何がリセットされ、何が引き継がれるか

プレステージは、本物のインクリメンタルゲームとプログレスバー付きのクリッカーを分けるメカニクスです。Steamの説明はそれについて率直です。リセット後でも、より深いフロアへ到達するのに役立つ強力なプレステージボーナスを通じて進行が続く、と。

実用的な意味は、リセットは決して損失ではないということです。それは変換です。意味のある進捗を生み出さなくなった周回を、次の周回をより先へスタートさせる永続的な倍率と交換しているのです。

| 要素 | プレステージで通常リセットされる | 通常は永続 |
|---|---|---|
| 現在のフロア深度 | はい | いいえ |
| 周回レベルのリソース | はい | いいえ |
| アンロック済みヒーローとロスター | いいえ | はい |
| 永続アップグレードの購入 | いいえ | はい |
| プレステージボーナス | いいえ | はい — しかも積み重なる |

プレステージ層を本当のスコアボードとして扱いましょう。フロア深度はスナップショットであり、プレステージボーナスはトレンドラインです。プレステージして、次の周回が数ループ以内に目に見えて深く到達しないなら、アップグレードの使い方がおそらく狭すぎたのです — 耐久力が必要なときにダメージを買った、あるいはその逆です。

## よりクリーンで速いループのための実践的なヒント

これらは、効率的なプレイヤーと行き詰まりを感じるプレイヤーを一貫して分ける習慣であり、ゲーム自体の設計上の優先事項とインクリメンタルRPGに関する一般的なコミュニティの経験から導かれたものです。

- **壁にぶつかるまで押し進め、そこで止める。** すでに楽にクリアできるフロアを周回するのは、通常その周回をプレステージの進捗に変換するよりも劣ります。
- **深さより広さを先に買う。** 小さな永続アップグレードの広がりは複利的に効きますが、単一の高価なアップグレードはそうではありません。
- **プレステージのたびにパーティを組み直す。** 浅い深度で機能した役割は、新しいボーナスが解放するより深いフロアでは生き残れないかもしれません。
- **勝利ではなく全滅を見る。** 終わった周回は、成功する10回の周回よりも多くを教えてくれます。
- **実績を進行チェックリストとして確認する。** このゲームには29個のSteam実績があり、まだ触れていないシステムの大まかなロードマップとして機能します。
- **周回を回し続ける。** その場を離れるなら、閉じるのではなくループをバックグラウンドで続行させましょう。

| 症状 | 考えられる原因 | 対処法 |
|---|---|---|
| パーティが同じフロアで繰り返し全滅する | 生存性が足りない | アップグレードを前線と回復に寄せる |
| 周回は遅いが決して失敗しない | 深度に対してダメージが低すぎる | 遠距離ダメージやダメージ強化シナジーを加える |
| プレステージが無意味に感じる | リセット前の投資が少なすぎる | まず永続アップグレードをより多く確保する |
| 新しいヒーローが弱く感じる | パーティのバランスが崩れている | 生のステータスではなく役割のカバレッジを中心に組み直す |

## FAQ

**Loop Dungeon Incrementalでは1回のダンジョンループにどのくらいかかりますか？**
ループの長さは深度とパーティのパワーに応じて変わります。序盤のループは自動戦闘が弱いフロアを素早く片付けるためすぐに解決します。深いループは敵がスケールし、全滅の可能性が高まるにつれて長くなります。設計意図は、ループが快適に繰り返せる程度に短いことであり、だからこそプレステージのリセットは罰ではなく進歩のように感じられるのです。

**プレステージするとヒーローを失いますか？**
いいえ。プレステージは永続的な進捗を保持するように設計されています — アンロック済みのヒーロー、永続アップグレード、プレステージボーナスはすべて引き継がれます。リセットされるのは現在の周回の深度と周回レベルのリソースです。

**Loop Dungeon Incrementalのダンジョンループはパッシブにプレイできますか？**
はい。戦闘は自動で、ゲームはアクティブな最適化とパッシブな進行の両方を明示的にサポートするように作られています。パッシブプレイは全滅に応じてパーティを調整しないため遅くなりますが、進行が完全に止まることはありません。

**最初に何をアップグレードすべきですか？**
最初の数ループでは、生のダメージよりも生存性と役割のカバレッジを優先してください。1フロア多く生き残るパーティは、わずかに速く敵を倒すがより早く全滅するパーティよりも多くの戦利品を生み出します — そしてより多くの戦利品は、その後のすべてのループにおける永続的な成長を速めます。

結論：Loop Dungeon Incrementalのダンジョンループは変換エンジンです。周回は燃料、永続アップグレードはエンジン、プレステージはギアチェンジです。ループをスロットマシンではなくシステムとしてプレイすれば、深さは自然とついてきます。
