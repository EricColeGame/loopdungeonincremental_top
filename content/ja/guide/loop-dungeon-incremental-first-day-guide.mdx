## プレイ前に起動クラッシュを修正する

Steamハブで報告されている初日の最大の障害は、Windows 11での起動時クラッシュで、「Fatal error: Failed to load il2cpp」というメッセージが出るものです。開発者は原因をWindows 11のSmart App Controlに突き止めました。これがゲームの署名されていないUnity DLLの読み込みをブロックしているのです。コード署名済みビルドは準備中ですが、それまでは以下の修正を順番に試してください。

| 順序 | 修正 | 方法 |
|---|---|---|
| 1 | ゲームファイルのブロック解除 | Steamライブラリ → ゲームを右クリック → 管理 → ローカルファイルを閲覧 → Ctrl+A → 右クリック → プロパティ → 「ブロックの解除」にチェック → 適用 → 再起動 |
| 2 | セキュリティ定義の更新 | Windowsセキュリティ → ウイルスと脅威の防止 → 更新を確認 → 再起動 |
| 3 | DirectX 11を強制 | Steamの起動オプションに `-force-d3d11` を追加（起動クラッシュに対するコミュニティ報告の回避策） |
| 4 | 報告する | 開発者にWindows 11のビルド、エラーのスクリーンショット、試した修正を送る |

ゲームが問題なく起動する場合でも修正#1は行ってください。30秒で済み、セッション途中のクラッシュを防げます。また、ゲームは常に最新の状態に保ちましょう。発売後のパッチですでに、誤ったアップグレード情報を表示するツールチップのバグが修正されています。これはまさに最初の1時間で判断を誤らせる類のものです。

## 最初のパーティは生のダメージではなくシナジーで組む

正式版ではバーストダメージのヒーローであるローグが追加され、プリーストには他のヒーローの能力と相互作用する「Activate」という新スキルが与えられました。この2つの事実は、どんなティアリストよりも最初の編成を形作るべきです。Activateはコンボの起点であり、他のヒーローのスキルの効果を変えるため、単一のダメージタイプだけで組んだパーティは価値を取りこぼします。

| ヒーロー | 役割 | 初日のアドバイス |
|---|---|---|
| プリースト | サポート兼コンボエンジン | 早めにActivateをセットし、他のヒーローのスキルがどう変わるか観察する |
| ローグ | バーストダメージ（正式版で追加） | 短いフロアでは強力な切り札。持続回復源と組み合わせる |
| メイジ | 遠距離ダメージ、アンロック制 | 正式版でアンロックすれば信頼できる後衛 |
| その他のヒーロー | さまざま | 実験する — 開発者も想定外のコンボを見つけるよう明言している |

この**Loop Dungeon Incremental 初日ガイド**の枠組みから導かれる、最初のパーティのための実践ルール3つ：

- **持続回復1、ダメージ2。** 回復がなければ長いフロアで足止めされ、ダメージがなければそこへ到達できません。
- **すべてのヒーローでActivateを試す。** このスキルの価値は何を変更するか次第なので、最初の2ループでロスター全体に回しましょう。
- **負けるたびに組み直さない。** 失敗したループでも通貨は貯まります。1体ずつ入れ替えて、何が変わったかを把握しましょう。

## 最初のループにおけるアップグレードの優先順位

インクリメンタルゲームは序盤に広さ、後半に深さを報います。このゲームも例外ではありません。Steamフォーラムのプレイヤー体験では、基本的にレベルごとに購入して前進するシステムと説明されており、買えるようになった瞬間にすべてを買いたくなる誘惑があります。最初の1時間はそれを我慢してください。

| 優先度 | アップグレードの種類 | なぜ先なのか |
|---|---|---|
| 1 | 安価で広範なステータス強化 | 小さな割合上昇がすべてのヒーローとすべてのフロアに適用される |
| 2 | ヒーローのアンロック | ヒーローが増えればActivateの対象もシナジーの選択肢も増える |
| 3 | 持続回復と生存性 | リセット前に1回のループで到達できる深さを伸ばす |
| 4 | 深い特化 | どのヒーローがランを支えるか分かってから初めて価値が出る |
| 5 | 外見や利便性の購入 | 深さへの影響はゼロ。最初のプレステージ後に取っておく |

もう一つ計画しておくべきこと：アビリティはデフォルトで手動発動です。コミュニティメンバーは自動発動オプションを明確に要望しており、アビリティ管理を繰り返しのクリックと表現しています。それが実装されるまではリズムを決めましょう。まずバフ、次にバースト、そして持続回復。これで戦闘中の慌てがなくなります。コントローラーや小型キーボードでプレイするなら、後から慣れるのではなく早めにキーを再割り当てしましょう。

## プレステージ、ロックされたスキル、初日のミス

プレステージは、初日のプレイヤーの多くが感想を固める場所です。このシステムはランの進行をボーナス通貨に変換し、その通貨で既に持っていたアップグレードを再選択します。これは一部のプレイヤーには報われないと感じられ、他のプレイヤーには戦略的と映ります。コミュニティ報告を正直に言えば、これは新規アンロックツリーではなく再購入システムです。それを分かって臨めば、はるかに不満は少なくなります。

| ミス | 起こること | より良いアプローチ |
|---|---|---|
| デモのセーブをインポートした状態でプレステージする | プレイヤー報告によれば、正式版でも一部スキルが再ロックされ「get the full version」と表示されることがある | ゲームファイルを検証し、セーブ情報を添えて開発者に報告する |
| すべてのアップグレードを即購入する | 通貨が消え、ビルドに個性がなくなる | 上記の優先順位表に従い、ティア5は飛ばす |
| 可能になった瞬間にプレステージする | 最高のヒーロー組み合わせを試す前にリセットしてしまう | もう1ループ走らせて、自分のキャリーを確認する |
| 無限のスケーリングを期待する | 数時間でコンテンツは終わる。レビュアーの多くが終わりが早いと指摘 | 1〜2回のセッションで全体を終えるつもりで、それに基づいて評価する |

**Loop Dungeon Incremental 初日ガイド**の読者への要点はシンプルです。プレステージはループをより速く繰り返すための道具であり、コンテンツの蛇口ではありません。最初のリセットでは、実際に自分を支えたアップグレードだけを買い直し、それ以外は必要になるまで飛ばしましょう。

## よくある質問

**Loop Dungeon - Incremental の最初のセッションはどのくらいが目安ですか？**
コミュニティ報告では、2〜3時間でゲームの内容のほとんどをカバーできるとされています。最初のプレイには90分を確保すると、少なくとも1回のプレステージサイクルを完了し、なお実験する時間も残ります。

**この Loop Dungeon Incremental 初日ガイドはパッチ後も役立ちますか？**
はい。構造的なアドバイス（起動問題の修正、持続回復1＋ダメージ2、広範なアップグレードを先に買う）はバージョン番号に依存しません。変わりうるのは、開発者がコード署名済みビルドを出した際の具体的な回避策リストだけです。

**Windows 11でゲームが起動しません。最初に何を試すべきですか？**
Steamのローカルファイルブラウザからゲームファイルのブロックを解除し、Windowsセキュリティの定義を更新して再起動します。それでもだめなら `-force-d3d11` の起動オプションを試し、Windowsのビルドとスクリーンショットを添えて開発者に連絡してください。

**プレステージするとすべて失いますか？**
ランのアップグレードは失いますが、リセットでボーナス通貨が得られ、それを永続的な再購入に使います。ヒーローやシステムとしてアンロックしたものが恒久的に消えることはありません。ただし、デモのセーブをインポートした場合にスキルロック表示のバグが起きたという報告はあります。

Loop Dungeon - Incremental の初日は順序がすべてです。ランチャーを修正し、持続回復1とダメージディーラー2のパーティを選び、深いアップグレードより安価で広範なものを先に買い、最初のプレステージをゴールではなく繰り返せるルーティンとして扱う。そうすれば、2〜3時間の流れは急いだものではなく、密度の濃い完全な体験として残ります。ダンジョンのループは短いのですから、準備は短くある必要はありません。
