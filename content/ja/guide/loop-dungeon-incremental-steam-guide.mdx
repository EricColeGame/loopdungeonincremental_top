## 最初の1時間の優先順位：スケールするランを整える

あらゆるインクリメンタルの最初の1時間は、2時間目から10時間目がスムーズに感じられるか、それとも作業的に感じられるかを決めます。この**Loop Dungeon Incremental Steamガイド**では、最初の1時間はセットアップとして扱い、深さを競う時間とは考えません。深さは後から来るものであり、まずは複利が優先です。

ほとんどのプレイヤーが収束する優先順位は次の通りです：

| 優先度 | 行動 | なぜ重要か |
|---|---|---|
| 1 | 早期に買えるヒーローアーキタイプをすべてアンロックする | ロスターの選択肢が増えれば、後のシナジー構成が広がる |
| 2 | 進行が目に見えて停滞するまで深さを押し進める | 停滞こそがシグナルであり、固定の階層数ではない |
| 3 | 1ラン限りのパワーより恒久アップグレードを買う | ランパワーはリセットされるが、恒久分は残る |
| 4 | リセット前に使い過ぎず戦利品を貯める | プレステージ価値は通常、蓄積された進行度に応じてスケールする |
| 5 | 1ランにつき新しいシナジーを1つだけ試す | 変数を切り分けることで、何が実際に機能するか分かる |

覚えておきたい経験則をいくつか：

- **単一の「最強」ヒーローを追いかけない。** パーティの強さは役割の網羅性から来るもので、1人のキャリーからではありません。
- **数字ではなくランを見る。** スクワッドが体力を目に見えて残してフロアをクリアしたなら、さらに押し進める余力があります。
- **最初の数回は早めにリセットする。** 序盤のプレステージボーナスは安価で、そのそれぞれが天井を引き上げます。
- **メモを取る。** 「到達フロア / 使用ヒーロー / 購入アップグレード」の2行のログでも、当て推量よりはましです。

Steamフォーラムやレビュー欄でのコミュニティの報告では、序盤は最初のプレステージまで遅く感じられ、その後急激に加速するという声が頻繁に挙がっています。これは設計と一致します。プレステージボーナスこそが本当の進行レイヤーなのです。

## パーティ構築とシナジー：ランの勝敗が決まる場所

新規プレイヤーが犯す最大の過ち——そしてこの**Loop Dungeon Incremental Steamガイド**が最も強く叩くポイント——は、パーティをダメージ競争として扱うことです。そうではありません。これは網羅性の問題です。前線の耐久力、持続的なダメージ、そして現在のアップグレードプールが報いるユーティリティが欲しいのです。

序盤から中盤のほとんどの状況で機能するバランスの取れたテンプレート：

| 役割 | 目的 | スロットの指針 |
|---|---|---|
| 前衛 / タンク | ダメージを吸収し、後衛がより長く生き残れるようにする | 常に最低1人は埋める |
| 持続ダメージ | 長期戦でも安定した火力 | 2人が通常は安全 |
| バースト / フィニッシャー | 停滞した戦闘が悪化する前に終わらせる | 1人、必要に応じて入れ替え |
| ユーティリティ / サポート | シナジーを成立させ、パーティを生かし続ける | フレックスの1枠 |

どのヒーローをアンロックしていても通用する3つのシナジー原則：

1. **同じ軸にボーナスを積み上げる。** アップグレードが特定のダメージタイプや役割を優遇するなら、焦点を分散させるのではなく、それに合わせてパーティを組む。
2. **すでに編成しているヒーローを強化する。** 毎回のランで使うヒーローへの控えめなアップグレードは、ベンチのヒーローへの大きなアップグレードに勝る。
3. **ロスター全体ではなく、1枠だけを回す。** すべてを一度に変えると、何が改善されたのか学べなくなる。

戦闘が自動であるため、ラン中にあなたが持つ本当のレバーは、持ち込んだ編成だけです。だからこそプリラン画面がゲームで最も重要な画面となります——そこに余分な30秒をかけましょう。

## プレステージのタイミング：いつリセットし、いつ待つか

プレステージはLoop Dungeon - Incrementalの心臓部であり、レビュースコアが割れるのもここです。リセットが少なすぎるプレイヤーはゲームを遅いと評し、リセットが多すぎるプレイヤーは無意味だと評します。最適点は、次のランの開始パワーを意味のある形で引き上げるリセットです。

| 状況 | 推奨アクション |
|---|---|
| 新しいアップグレードなしで複数ループ停滞している | 今すぐリセット |
| 主要な恒久アップグレードをちょうどアンロックした | あと1ラン押してからリセット |
| まだ新しいヒーローやシステムをアンロック中 | 待つ — まずアンロックを完了させる |
| 序盤の立ち上がりを変えるプレステージボーナスを買える | 即リセット |
| 迷っている | リセット — 無駄なランのコストは無駄な1時間より安い |

有用なメンタルモデル：**プレステージは、現在のランが最大値に達したときではなく、リセット後に次の恒久アップグレードが手の届く範囲にあるときに行う。** ランを最大化するのは生産的に感じられますが、たいていは複利を遅らせるだけです。ストアページではプレステージボーナスを「より深いフロアに到達する助けとなる」メカニズムと説明しており、これは深さは買うものであって、延々と削り出すものではないという強いヒントです。

もう一つ注目すべき点：このゲームにはSteam実績が29個あります。そのうちいくつかはマイルストーン進行——初回ラン、クラスアンロック、マスタリー系の目標——に紐づいているようです。実績ハンターなら、序盤に数回リセットする方が、1回の長い作業より「初回ラン」とクラスアンロックの層を早くクリアできるでしょう。

## Windows 11の「Failed to Load il2cpp」クラッシュを修正する

リリース時に、開発者はWindows 11での起動クラッシュに関する告知を投稿しました。メッセージは「Fatal error: Failed to load il2cpp」です。これはインストールの破損ではなく、ゲームのロジックのバグでもありません——Windows 11のSmart App ControlがUnity IL2CPPランタイムをブロックしているのです。この手順を飛ばす**Loop Dungeon Incremental Steamガイド**は不完全です。なぜなら、ゲームが起動しなければ他のすべては意味をなさないからです。

| 手順 | アクション |
|---|---|
| 1 | エラーテキストが「Failed to load il2cpp」と一致することを確認する |
| 2 | Windowsセキュリティ → アプリとブラウザーの制御 → Smart App Control を開く |
| 3 | Smart App Controlをオフにする（注意：Windowsは再インストールなしでは再有効化できない場合があります） |
| 4 | ゲームを再起動する |
| 5 | それでも失敗する場合は、Steamでゲームファイルを検証し、固定された告知を確認する |

ここでの権威ある情報源は開発者自身の告知であり、システム設定をいじり始める前に読む価値があります。Smart App Controlを無効化することに抵抗があるなら、まずファイルを検証し、告知スレッドを確認してください——開発者は返信で積極的に活動しています。

最低スペックは控えめです：64ビットのWindows 10、Intel Core i3-2100またはAMD同等品、統合Intel HD Graphics 4000、ストレージ500MB。執筆時点でSteam Deck互換性は**Unknown**と表示されているため、携帯機でスムーズに動くとは考えないでください。

## FAQ

**Loop Dungeon - Incrementalは無料で遊べますか？**
いいえ。$4.99の有料ゲームで、11月2日まで10%のイントロ割引により$4.49になります。購入前にループを試したい場合はSteamで無料デモが利用可能です——Mixedのレビュースコアを踏まえると、まずデモを試すのが賢明な選択です。

**Loop Dungeon - Incrementalではどのくらいの頻度でプレステージすべきですか？**
現在のランが目に見えて停滞し、その後に次の恒久アップグレードが手の届く範囲にあるときはいつでもリセットしてください。序盤は頻繁なリセットを意味し、数ループだけでリセットすることもあります。後半は各プレステージボーナスが天井を引き上げるため、ランは長くなります。迷ったらリセットしましょう。無駄なランのコストは無駄な1時間より安いのです。

**このLoop Dungeon Incremental Steamガイドは受動的なプレイヤーにも当てはまりますか？**
はい。戦闘は完全に自動なので、ここにあるほぼすべて——パーティ構成、アップグレード優先順位、プレステージのタイミング——は、能動的に見ていても定期的にチェックするだけでも当てはまります。手を動かす必要がある唯一のセクションは、Windows 11のクラッシュ修正です。

**なぜゲームは起動時に「Failed to load il2cpp」でクラッシュするのですか？**
Windows 11のSmart App ControlがUnity IL2CPPランタイムをブロックしています。開発者のリリース告知がこの問題を文書化しており、既知の回避策は再起動前にSmart App Controlを無効化することです。エラーが続く場合は、その後Steamでゲームファイルを検証してください。

**Steam Deckで検証済みですか？**
執筆時点で互換性はUnknownと表示されているため、確定した判定はありません。携帯機でのプレイを計画する前に、ストアページの互換性バッジを確認してください。
