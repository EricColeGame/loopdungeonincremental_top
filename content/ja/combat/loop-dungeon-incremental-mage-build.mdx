## Loop Dungeon - Incremental でメイジがパーティの軸になる理由

メイジは乱雑なループを一掃してくれる存在ですが、計画なしで運用すると、あらゆる部屋でじわじわとダメージを失っていきます。Loop Dungeon - Incremental ではパーティがダンジョンのループを繰り返すあいだに、戦利品と永続アップグレードを蓄積していくため、ヒーローに関するあらゆる判断が複利的に効いてきます。焦点を絞った Loop Dungeon Incremental メイジビルドは、その複利効果を「敵が動く前に部屋をクリアする」形へ変換する最短の道です。

多くのプレイヤーはメイジを汎用のダメージ枠として扱います。アンロックして、買えるものを買って、次へ進む。それでも最初の数ループは機能しますが、やがて頭打ちになります。本当の Loop Dungeon Incremental メイジビルドとは一連の選択の積み重ねです。すなわち、戦闘中にメイジが何をするのか、誰がその火力を増幅するのか、そしてプレステージ後に最初に何を買うのか、という選択です。

Loop Dungeon - Incremental はソロ開発のパーティクローラーで、ヒーローたちを終わりのないループへ導き、戦利品を集め、ランとランのあいだに永続アップグレードを解放していきます。正式リリースではヒーロー、スキル、ボス、レベルが追加され、バースト重視のローグや、プリーストの新スキル「Activate」も登場しました。パッチノートやプレイヤーの議論は [Loop Dungeon - Incremental Steam コミュニティハブ](https://steamcommunity.com/app/4621970) で追えます。

何時間も投資する前に知っておきたい注意点がひとつあります。コミュニティの報告によると、デモ版のセーブデータを正式版へ引き継いだ場合、最初のプレステージ後にメイジがロック状態で表示されることがあるそうです。ゲームを所持しているのにメイジがアンロックされない場合は、ビルドの問題ではなく報告済みのバグとして扱いましょう。

## Loop Dungeon Incremental メイジビルドの核となる柱

強いメイジ構成はどれも、同じいくつかの柱の上に成り立っています。すべてを同時にそろえる必要はありません。必要なのは、いま自分のパーティがどの柱で失敗しているのかを見極めることです。

| 柱 | 実際の見え方 | 優先度 |
|---|---|---|
| ダメージ稼働率 | メイジがクールダウン間で待機せず、唱え続けている | 高 |
| キャストのタイミング | 強力なアビリティがはぐれ敵ではなく密集した敵に当たる | 高 |
| パーティによる増幅 | バフやスキル連携がメイジのダメージに還元される | 高 |
| 生存力 | 前線のヒーローが敵をメイジから引き離す | 中 |
| 経済規律 | ループ通貨が贅沢品よりメイジの道に回る | 中 |

機能するビルドと、買い物の山を分ける習慣は2つあります。

- **ループごとにレーンを決める。** このループは生のダメージ、稼働率、パーティ支援のどれを狙うのかを決め、そこにだけ使う。
- **アップグレードは数字ではなく戦闘で判断する。** 購入が次の部屋を目に見えて短縮しないなら、それはダメージアップグレードではなかったということです。

ここで、ゲームのプレステージシステムに関するコミュニティの声に耳を傾ける価値があります。何人かのプレイヤーは、すでに持っていたアップグレードを買い直すことになるため、リセットを「負担が重く報われない」と表現しています。その不満は実のところ計画性の問題です。買い直しの順序を書き出した Loop Dungeon Incremental メイジビルドは、その場の思いつきで進めるビルドとはまったく別物に感じられます。

## メイジのダメージを倍加させるパーティシナジー

メイジは単独で担う存在ではありません。真価が現れるのは、別のヒーローが場を整えてくれるときです。敵をまとめる、その場に留める、あるいは適切なタイミングでスキル連携を発動する。そうした動きがメイジを支えます。

| パートナー | もたらすもの | メイジとの使い方 |
|---|---|---|
| プリースト | Activate スキルが他ヒーローのスキルと独特な形で相互作用する | メイジの最も重いキャストの直前に Activate を発動する |
| ローグ | 優先目標への高バーストダメージ | ローグに脅威を消させ、そのあとメイジが群れを仕留める |
| 前線ヒーロー | 圧力を受け止め、敵を密集させ続ける | 敵の群れが範囲ダメージ内に収まるよう位置取る |
| サポートまたはヒーラー | 長いループでもパーティを維持する | 深い部屋でのメイジの詠唱時間を延ばす |

### Activate は最大キャストに合わせて使う

プリーストの Activate は、メイジ使いにとってゲーム内で最も興味深いレバーです。なぜなら、他ヒーローのスキルと明示的に相互作用するからです。これを撃ちっぱなしのボタンではなく、自分の最強アビリティにかかる倍率として扱いましょう。クールダウンごとに Activate を撃てば平均的な価値しか得られませんが、メイジの最強スキルが準備できた瞬間まで温存すれば、実際に戦闘を終わらせるスパイクになります。

### バーストヒーローにメイジの下準備をさせる

ローグは素早く敵を消すために存在します。それはダメージの取り合いに見えますが、実態は下準備です。バーストヒーローは、範囲ダメージだけでは生き残ってしまう敵を排除し、部屋を短縮し、パーティが受ける継続的な小ダメージを減らします。バーストと持続的な詠唱を組み合わせるのが、Loop Dungeon Incremental メイジビルドにおいて最も信頼できる2ヒーローの核です。

## メイジのためのプレステージと永続アップグレードの順序

プレステージは、ほとんどのメイジビルドが勝つか負けるか決まる場所です。リセットのたびにアップグレードを選び直すため、総量よりも順序が重要になります。

| プレステージ段階 | 最初に使う先 | なぜ最初なのか |
|---|---|---|
| 最初のリセット | メイジの核となるダメージ経路 | クリア速度を即座に取り戻し、次のループを速くする |
| 2回目のリセット | メイジに関わるシナジーとパーティ強化 | 多くのループを重ねると、複利的価値がフラットなステータスを上回る |
| 3回目以降 | ユーティリティと快適性 | ダメージの下限が安定したら、周回を滑らかにする |

同じビルドをループ段階ごとに評価するなら、次のようになります。

| ループ段階 | メイジの役割 | 注意すべき点 |
|---|---|---|
| 序盤ループ | 雑魚を素早く安く処理する | 単体ダメージへの過剰投資 |
| 中盤ループ | パーティとのシナジーを積み上げる | 前線の生存力の軽視 |
| 深いループ | ボスへダメージを集中させる | ボス部屋の手前で息切れする |

手動操作についてひとこと。プレイヤーのなかには、絶え間ない詠唱を「フラスコピアノ」と表現して、アビリティのオートキャストを要望する声もあります。その感覚に共感するなら、小さなキャストを数多く重ねるのではなく、少なく大きく唱える方向へビルドを寄せましょう。1部屋につき大きな見せ場が3回ある Loop Dungeon Incremental メイジビルドは、常時入力が求められるビルドよりずっと操作しやすくなります。

## メイジのダメージを静かに殺すミス

失敗したメイジのランは、劇的に崩れるのではなく、じわじわと色あせていきます。数字の上ではダメージは問題なさそうに見えるのに、部屋に時間がかかり、パーティはより多くの小ダメージを受け、ループは本来より早く終わってしまいます。

| ミス | 気づく症状 | 対処 |
|---|---|---|
| メイジを唯一のダメージ源にする | メイジが倒れた瞬間にパーティが停止する | ローグのようなバーストヒーローを加える |
| タイミングではなくクールダウンで撃つ | 敵が動いたあとにアビリティが当たる | 大きなキャストは密集した群れまで温存する |
| 買えるものを全部買う | ビルドの個性がなく、スパイクが弱い | ループごとに柱を2つに絞る |
| 生存力を完全に省く | 部屋の前半でメイジが死ぬ | ダメージより先に前線へ投資する |
| プレステージ後にランダムに買い直す | リセットが遅く、作業的になる | リセット前に買い直しの順序を書き出す |

早期に断ち切る価値のある習慣がもう2つあります。1つ目は、Loop Dungeon Incremental メイジビルドを1部屋だけで評価しないこと。1ループ全体で判断しましょう。インクリメンタルゲームは、まとめて使うより一貫性を報いるからです。2つ目は、パーティ画面を無視しないこと。優れたスキルを持っていても前線が紙なら、そのメイジは戦闘時間の半分を死んで過ごすメイジです。

Steam ハブでのプレイヤー体験には、ゲーム全体のボリュームに関する指摘もあります。何人かのレビュアーは、現状のコンテンツをおよそ2時間で終えられたと報告し、ビルドの多様性が限られているとも述べています。これは心に留めておくべき妥当な批判です。つまり、あなたのメイジビルドは100時間かけて伸ばすプロジェクトではなく、コンパクトな1ランに最適化すべきだということです。最初の数ループで報われる判断を、前倒しで行いましょう。

## Loop Dungeon Incremental メイジビルド FAQ

**優れた Loop Dungeon Incremental メイジビルドと、ただメイジを使うだけの違いは何ですか？**
意図です。メイジをアンロックしてアップグレードを買うだけなら誰でもできます。ビルドとは、メイジを何のために使うのかを決めることです。持続的な範囲ダメージなのか、ボスの仕留め役なのか、シナジーの起点なのか。そして、そこにだけ使うこと。さらに、プレステージ後にその場で考えるのではなく、買い直しの順序を把握しておくことでもあります。

**メイジと最初に組むべきヒーローは誰ですか？**
最も興味深いパートナーはプリーストです。Activate が他ヒーローのスキルと相互作用するため、最大キャストに合わせるタイミングのレバーが手に入ります。とにかく部屋を早く終わらせたいなら、ローグがよりシンプルな答えです。バーストダメージが、範囲ダメージでは残ってしまう敵を排除してくれるからです。

**正式版でメイジがロックされているのですが、ビルドの問題ですか？**
おそらく違います。コミュニティの報告では、デモ版のセーブを正式版へ引き継ぐと、正式版を所持しているにもかかわらず最初のプレステージ後にメイジがロック表示されたとされています。それは報告済みのバグであり、あなたの Loop Dungeon Incremental メイジビルドのミスではありません。

**メイジビルドはどれくらいで機能し始めるべきですか？**
プレイヤーがゲームのコンテンツをおよそ2時間で終えられると報告していることを踏まえると、ビルドは最初の数ループ以内に機能している感覚があるはずです。そうでないなら、購入が薄く広がりすぎている可能性が高いです。何より先に、ダメージ稼働率とキャストのタイミングへ集中しましょう。

メイジは、2ループ先まで計画するプレイヤーに報いてくれます。柱を選び、大きなキャストのタイミングを合わせ、適切なパートナーでビルドを支えれば、ダンジョンは思っているよりずっと早く崩れ始めるはずです。
